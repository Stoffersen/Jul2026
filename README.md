# 🎄 Jul i den gamle Humlehave
Familiens julehovedkvarter for Peter, Ditte, Caroline og Christine — julen 2026 i Sønderborg.

Mobil-first juleapp med gavehemmeligheder, Ønskeskyen-links, mad og indkøb, enkel kalender, Nordjylland-ekspedition og frivilligt julehalløj.

## Kør lokalt
```bash
npm install
npm run dev
```

## Roadmap
- Individuelle logins og privat gave-model
- Gavecentral + Ønskeskyen-links
- Julemenu, indkøb og juleaftens-cockpit
- Enkel familiekalender
- Terndrup/Aabybro-ekspedition
- Quiz, missioner og andet julehalløj
- PWA/offline

> Hyggen er obligatorisk-ish. Aktiviteterne er ikke.
